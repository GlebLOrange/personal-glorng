# First-visitor QA index

Round-based, screenshot-backed usability evidence for the public portfolio. This index separates intentional product decisions from issues that need follow-up. Screenshots are observations from their recorded rounds; Playwright captures a fresh mobile dialog screenshot as a test attachment on each run.

## Intentional product decisions

| Decision                                | Expected public behavior                                                             | Source                                                                                             |
| --------------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| Pricing page is intentionally absent    | `/pricing` displays the app's not-found page; hiring is discussed through inquiry    | [intentional-gaps.md](intentional-gaps.md), [security reference](../../docs/reference/security.md) |
| Terms page is intentionally absent      | `/terms` displays the app's not-found page; this portfolio is not a packaged product | [intentional-gaps.md](intentional-gaps.md), [security reference](../../docs/reference/security.md) |
| Public signup is intentionally disabled | Operator accounts are provisioned by the owner; public registration returns 403      | [intentional-gaps.md](intentional-gaps.md), [security reference](../../docs/reference/security.md) |

Do not file these as bugs or add public routes/signup without a product decision.

## Run the regression

From `client/`, run `npm run e2e -- e2e/contact-journey.spec.ts`. The test captures a current mobile dialog image as a Playwright attachment; compare it with the linked round screenshots when reviewing visual or interaction changes. Tests intentionally do not submit inquiries.
